# digital-ema

文化祭の「神社」展示を目的として開発された、デジタル絵馬アプリケーション。  
来場者が奉納した願いを大型モニターにリアルタイムで表示し、会場全体で共有する体験を提供します。

## 機能
- ニックネームと想いを送信すると、絵馬としてモニターに表示される
- 新規の奉納があると、画面上部にその旨が通知される
- 当日に奉納された願いのみが、一定間隔で更新されながら表示される
- 全日程の願いはアーカイブ画面に集約され、後日の閲覧が可能である
- スマートフォンからも奉納できる

## 来場者の動き
1. 受付端末でニックネームと想いを入力する
2. 送信と同時に、モニター上で「○○さんの想いが奉納されました」と通知される
3. 一定時間ののち、自身の願いが絵馬として画面に現れる
4. 他者の願いを探したり、アーカイブ画面で過去の奉納を振り返ったりできる

## 動作の流れ
Googleフォームに入力されたデータは、スプレッドシートに自動保存される。  
GAS（Google Apps Script）がその内容を定期的に取得し、GitHub Pages上のフロントエンドへJSON形式で提供する。  
ブラウザ側で絵馬として描画され、大型モニターに出力される。

## 使用技術
- **フロントエンド**：HTML / CSS / JavaScript
- **バックエンド（API）**：Google Apps Script
- **データ保存**：Google スプレッドシート
- **入力フォーム**：Google フォーム
- **ホスティング**：GitHub Pages

## 表示ロジック
メイン画面には、当日に奉納された願いのみが表示される。  
30秒ごとに更新され、未表示の願いを優先して表示しつつ、枠に余剰がある場合は過去の願いからランダムに補完する。  
アーカイブ画面は全日程のデータを時系列順に一覧表示し、45秒ごとに最新状態へ更新される。

## 設計意図
単なる投稿掲示板ではなく、神社における絵馬奉納の体験をデジタルで再現することを意図している。  
奉納の瞬間を通知で可視化し、願いがモニター上に並ぶことで、参加感と共有感を生み出す設計とした。

## セットアップ手順
1. Googleフォームを作成（ニックネーム・想いの2項目）
2. スプレッドシートと連携させる
3. Apps Scriptでプロジェクトを作成
4. 本リポジトリのコードを複製する
5. `SPREADSHEET_ID` を自身のシートIDに書き換える
6. Webアプリとしてデプロイ（アクセス権限は「全員」）

## カスタマイズ
| 内容 | 変更箇所 |
|:---|:---|
| 表示枚数 | `DISPLAY_COUNT` |
| 更新間隔 | `setInterval` |
| 通知の最大人数 | `getRecentNicknames()` |
| ニックネームの文字数制限 | `maxLen` |
